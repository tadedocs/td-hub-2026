发柜前，先把柜算清楚

装柜不是拍脑袋。按箱规算，该几个柜、怎么分柜、走哪种柜型最省，一次算明白。

装柜计算按外箱尺寸估算，自动算出要几个柜、每柜装多少箱、装载率多少
重货先装按每箱毛重排序：重货进柜子最里侧和底层，轻货靠柜门；上方比下方重超过 10% 就不压，算不出"铁件压泡沫箱"这种装不出来的方案
混装填缝大小箱混装时自动补缝：大箱旁的窄条、零头列上方由后装产品填平，同票货可能少算一个柜
3D 排布图 + 装柜位置可旋转缩放的立体示意图，配装载步骤表：第几步、装什么、装在柜里侧还是门端、从柜底起还是踩在下层货上、怎么摆、多少件——装柜工照表就能上手
装柜单·一柜一页导出的是能直接发给装柜班组的作业文件：第 1 页单据（分柜明细 / 重心提示 / 签章），第 2 页起每柜一整页——该柜 3D 图、货物构成、分步作业表（装在哪、怎么摆、多少件、订单箱号）、签字栏。现场撕开一页一张
尾数回塞 · 少订一个柜最后一柜只装零星几箱时，自动把这批箱子补进前面柜的平整空位，实测同一张单从 5 柜降到 4 柜；必须满足不悬空、不重压轻、顶面够平才放，塞不下就给三条出路（摊回前柜 / 换小柜 / 走拼箱）
重心与加固体检逐柜给前后偏载、左右偏载、重心高度、柜门端空隙；超过柜长/柜宽 10% 标红，门端留空 ≥30cm 提示加固——偏载是码头拒装和拖车超轴的主因。托盘按柜宽居中摆放，不会因为排布本身虚报左右偏载
柜型对比20GP / 40GP / 40HQ 一次算完，填上海运费直接看哪种最省
装柜单导出带柜号、封条号、签字栏，可直接发给货代和仓库
箱规管理产品外箱长宽高填一次，以后每单自动带上；同一条码改了箱规，历史单据不受影响
使用前请知悉
  • 本软件为辅助测算工具，装柜结果、单据内容均不构成对装柜、订舱、报关、结汇效力的承诺或保证。
  • 装柜计算为理论最优估算值，实际可装箱数受摆放方向、堆叠层数、托盘、加固材料、柜内凹凸、码头与承运人限重影响，通常低于估算值；因超重、超尺寸、实际装载差异产生的拒装、罚金、退关或客户索赔，由使用者自行承担。
  • 软件生成的单据为商业自制文件，不是海关、商检、船公司出具的正式单证，正式报关、报检、结汇请以官方系统与签发机构为准。
  • 单据中的价格、费用、申报要素、交期等关键信息，发出前请务必自行核对。
激活方式
打开软件 → 右下角「输入授权码」→ 粘贴卖家给你的码 → 点激活。全程离线，不需要注册账号。

换电脑怎么办
在新设备上重新输入一次同一个授权码即可，不绑机器。单据和客户资料用「设置 → 导出备份」搬过去。

下载后打不开？
Windows 和 Mac 下载下来就是 .zip。解压后 Windows 得到一个「外贸单证与装柜系统」文件夹，进去双击同名 exe；Mac 得到一个 .app，拖进「应用程序」。请整个文件夹一起解压，不要只把 exe 拖出来，否则会提示找不到 app.html。
